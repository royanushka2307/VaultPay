How to Inspect the SQLite Database

instance/wallet.sqlite

Run these in your terminal from D:\secure_wallet - uses the project's Python, no extra tools needed.

1. AES-256-GCM encrypted card blobs
cd D:\secure_wallet; .venv\Scripts\python.exe -c "import sqlite3; [print(r) for r in sqlite3.connect('instance/wallet.sqlite').execute('SELECT id, masked_identifier, substr(encrypted_metadata,1,40) FROM payment_methods')]"
✓ Shows masked PAN + opaque Base64 ciphertext - no plaintext card data
2. Salted SHA-256 hashes (no plaintext passwords)
cd D:\secure_wallet; .venv\Scripts\python.exe -c "import sqlite3; [print(r) for r in sqlite3.connect('instance/wallet.sqlite').execute('SELECT username, substr(password_hash,1,20), substr(password_salt,1,20) FROM users')]"
✓ Shows hex hash + hex salt - zero plaintext passwords
3. Integer paise balances (no floats)
cd D:\secure_wallet; .venv\Scripts\python.exe -c "import sqlite3; [print(r) for r in sqlite3.connect('instance/wallet.sqlite').execute('SELECT user_id, balance_cents, balance_cents/100.0 FROM wallets')]"
✓ balance_cents is INTEGER - exact paise, no floating-point drift
